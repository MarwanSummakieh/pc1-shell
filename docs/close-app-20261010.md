# PS menu Close: wrapped Linux games — 10 October 2026

Installed on PC1 (`192.168.50.206`) at 16:20 Copenhagen time. This is a
persistent local bench update; the source fix is included for future images.

The reported Bloodborne close failure was confirmed in the live journal:
at 14:11:38 UTC the shell killed launcher PID `913934` and returned Home,
while its AppImage and `bb-probe` descendants remained alive in process group
`913934`. The direct launcher is `flock`, which does not stop its children
when killed.

`Launcher._kill_pid()` now signals the complete isolated Linux process group
before reaping its direct child. It reads `/proc/<pid>/stat` to verify that the
tracked PID is both the process-group leader and session leader before using a
negative group ID. A failed group termination keeps the application tracked.
The existing Flatpak, managed Windows and Steam shutdown paths remain in place.
Close retains its existing forced-termination semantics; Minimize preserves the
processes.

## Verification

- The new Linux regression runs the actual PS menu Close action against a real
  `flock → wrapper → game` process chain. Both foreground and minimized cases
  restore Home, remove all fixture processes and preserve an unrelated app.
  A second launch also verifies that no stale lock blocks relaunch.
- Controller Home, controller routing and embedded Steam shell suites pass.
  Export and isolated startup as the player user pass.
- On the installed shell, the Bloodborne card launched PID `1074741`, with
  AppImage PID `1074744` and native game PID `1075153`. At 14:23:27 UTC,
  the actual PS menu Close action terminated process group `1074741`.
  All three processes disappeared and Home returned to the Bloodborne card.
  This live check used the keyboard equivalent of system-menu navigation;
  the automated fixtures exercise the same menu action.
- The original orphan was closed after backing up its savedata. It ignored
  the window-close/TERM attempt and required group KILL. The native browser
  engine and controller broker were not replaced by this update.
